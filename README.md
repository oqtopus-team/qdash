# QDash

[![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)](https://opensource.org/licenses/Apache-2.0)
[![slack](https://img.shields.io/badge/slack-OQTOPUS-pink.svg?logo=slack&style=plastic)](https://join.slack.com/t/oqtopus/shared_invite/zt-3bpjb7yc3-Vg8IYSMY1m5wV3DR~TMSnw)
[![Documentation](https://img.shields.io/badge/docs-online-blue)](https://oqtopus-team.github.io/qdash/)

QDash is a web platform for running qubit calibration workflows, reviewing measurement results,
and tracking calibration parameters and their history.

<img src="docs/public/images/qdash-demo.gif" alt="QDash calibration demo" width="100%" />

[Watch the demo with sound](https://oqtopus-team.github.io/qdash/user-guide/what-is-qdash#demo)

## Start Here

- [Try QDash](https://oqtopus-team.github.io/qdash/user-guide/setup) with the Fake backend, then
  [run your first calibration](https://oqtopus-team.github.io/qdash/user-guide/first-calibration).
- [Connect hardware](https://oqtopus-team.github.io/qdash/user-guide/setup/qubex-backend) with the Qubex backend.
- [Use QDash](https://oqtopus-team.github.io/qdash/user-guide/) to run workflows, review results, and share findings.
- [Develop QDash](https://oqtopus-team.github.io/qdash/developer-guide/) to change and test the code.

Read [System Updates](https://oqtopus-team.github.io/qdash/user-guide/system-updates) before upgrading.
