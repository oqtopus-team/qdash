# Operator Guide

This guide is for people who run QDash, configure deployments, and support users.

Use these pages when you need to start the stack, change environment settings, check service
health, or understand how users interact with projects and workflows.

## Start Here

- [Setup](./setup.md): clone QDash, configure `.env` and Qubex, start Compose, and sign in.
- [Operations](./operations.md): start, stop, inspect logs, and handle common local failures.
- [Workflows](./workflows.md): understand Prefect, deployment-service, and user-flow-worker roles.

- [Reviewing and Sharing Results](../user-guide/reviewing-results.md): notes, issues, discussions, knowledge, and AI reviews.
